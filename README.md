## 🌟 Featured Project

### 🌿 [Mindfy](https://github.com/chinmaiunni/Mindfy)

Mindfy is a role-based mental wellness platform developed using Python and Django. It connects users with psychologists and yoga trainers through a unified web application.

#### Key Features

- Role-based registration and login
- Dedicated dashboards for each application role
- Psychologist consultation requests
- Session scheduling and booking
- User-to-psychologist chat
- Yoga and motivational video libraries
- Subscription plan management
- User complaints and administrator replies
- Feedback and homepage testimonials
- Psychologist and yoga trainer approval
- Administrative management system
