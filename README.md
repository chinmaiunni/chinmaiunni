## 🌟 Featured Project

### 🌿 [Mindfy](https://github.com/chinmaiunni/Mindfy)

A role-based mental wellness platform built with Python and Django. Mindfy connects users with psychologists and yoga trainers through a unified web application.

**Key features:**

- Role-based registration and login
- Psychologist consultation requests
- Session scheduling and booking
- User-to-psychologist chat
- Yoga and motivational video libraries
- Subscription plan management
- Complaints, feedback, and administrator replies
- Separate dashboards for users, psychologists, yoga trainers, and administrators

**Technology:** Python · Django · SQLite · Bootstrap · JavaScript · AJAX
